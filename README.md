# 灰烬佣兵

简约风格的挂机文字 RPG，使用原生 HTML、CSS 和 JavaScript 开发。当前版本：**v0.7.4**。

## 本地运行

无需安装前端依赖。在仓库目录运行：

```sh
python3 -m http.server 8765
```

访问 http://127.0.0.1:8765/dist/ 。也可直接打开 `dist/index.html` 试玩。

## 玩法

- 16 个区域，普通怪与精英自动战斗；发现首领后手动挑战，击败后解锁下一区域。
- 金币、32 种材料、13 个装备部位，以及装备强化、打造、建筑和训练。
- 雇佣兵和招募怪物共同出战，领主装备与特殊属性支持不同成长路线。
- 战后保留生命，返回营地恢复；包含死亡、自动撤退和离线结算。
- 实时战斗 → 领主属性与装备 → 功能页签；属性和装备详情使用悬停提示。

进度保存在浏览器 localStorage 中。不同浏览器、域名和端口的存档独立。当前为开发版本，长期进度节奏仍需玩家测试。

## 代码结构

| 文件 | 用途 |
| --- | --- |
| `dist/index.html` | 页面结构 |
| `dist/style.css` | 页面样式和轻动效 |
| `dist/content.js` | 区域、材料、装备和建筑数据 |
| `dist/engine.js` | 战斗、成长、掉落与离线结算 |
| `dist/game.js` | 页面渲染、交互与本地存档 |
| `dist/view-state.js` | 资源与升级可用状态 |
| `dist/feedback.js` | 战斗和掉落反馈 |
| `tests/` | 引擎、资源状态及首领解锁回归测试 |
| `docs/` | 游戏设计与数值模拟说明 |

## 验证

需要 Node.js，无需安装依赖：

```sh
npm test
```

测试覆盖材料与装备数量、生命恢复、死亡、掉落、招募、建筑、离线结算，以及普通战转首领、实际战斗胜利解锁和刷新保存等流程。
